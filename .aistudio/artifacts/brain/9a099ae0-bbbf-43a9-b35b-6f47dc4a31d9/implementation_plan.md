# تقسيم الأخطاء والمحفوظات والملاحظات هرمياً + فتح ملفات PDF خارجياً بشكل مباشر

تهدف هذه التحديثات إلى تنظيم خانات (أخطائي، محفوظاتي، ملاحظاتي) بشكل هرمي دقيق داخل صفحة المادة وفي التبويب العام لبنك الأتمتة، بالإضافة إلى تعديل سلوك فتح الملفات في المكتبة العلمية ليتم فتحها مباشرة كملف PDF خارجي (`application/pdf`) دون إظهار قائمة المشاركة (`Share Sheet`).

## قرارات المستخدم المعتمدة

> [!IMPORTANT]
> تم تأكيد القرارات التصميمية والوظيفية التالية بناءً على إجاباتك:

- **القرار المعتمد 1 (طريقة عرض تبويب «كامل»)**: عند اختيار تبويب **«كامل»** ضمن أخطائي أو محفوظاتي أو ملاحظاتي، يتم **عرض كل الأسئلة المطابقة مباشرة في صفحة واحدة** للتدرب السريع والمباشر.
- **القرار المعتمد 2 (نطاق التقسيم الهرمي)**: تطبيق التقسيم الهرمي الرباعي (**الأقسام · المحاضرات · شامل وجزئي · كامل**) **داخل صفحة كل مادة** وكذلك **في التبويب العام لبنك الأتمتة** (تبويبي الأخطاء والمحفوظات/الملاحظات).
- **القرار المعتمد 3 (فتح ملفات PDF خارجياً بدون مشاركة)**: عند الضغط على ملف تم تنزيله في المكتبة (أو اختيار فتح الملف خارجياً)، يتم **فتح الملف مباشرة كملف PDF خارجي** (`application/pdf`) عبر عارض الـ PDF في النظام دون استدعاء نافذة المشاركة (`navigator.share`).

## 1. نظرة عامة والمفهوم الأساسي

- **ما الذي يقدمه التحديث**:
  1. **هيكلة هرمية ذكية للأخطاء والمحفوظات والملاحظات**:
     - عند الدخول إلى **أخطائي** أو **محفوظاتي** أو **ملاحظاتي**، تظهر التبويبات الرئيسية الأربعة بشكل دائم وثابت حتى لو كان عدد العناصر فيها صفراً:
       **الأقسام** | **المحاضرات** | **شامل وجزئي** | **كامل**.
     - عند اختيار **الأقسام** أو **المحاضرات** أو **شامل وجزئي**: تظهر **فقط الفروع/المحاضرات التي تحتوي فعلياً على عناصر** (أخطاء أو محفوظات أو ملاحظات بحسب الخانة المختارة).
     - مثال عملي: إذا أخطأ الطالب في «المحاضرة الأولى» ضمن قسم «المحاضرات»، يضغط على **أخطائي** ← **المحاضرات** ← يظهر له فرع **المحاضرة الأولى** فقط (مع عدد الأخطاء فيها) ← وعند الضغط عليها تفتح أسئلة الأخطاء الخاصة بالمحاضرة الأولى للتدرب عليها وتصحيحها.
     - عند اختيار **كامل**: تظهر جميع الأسئلة المطابقة (من كافة الفروع) مباشرة في صفحة واحدة.
  2. **فتح ملفات PDF خارجياً بشكل مباشر**:
     - إلغاء استدعاء `navigator.share` عند فتح الملفات حتى لا تظهر قائمة المشاركة.
     - ضمان توليد وتمرير الملف بصيغة `application/pdf` قياسية وفتحه مباشرة كملف PDF خارجي عند الضغط على بطاقة الملف بعد اكتمال تنزيله.

## 2. تجربة المستخدم والتصميم البصري

### أ. مسار المستخدم داخل (أخطائي · محفوظاتي · ملاحظاتي)
1. **المستوى الأول (اختيار الخانة)**:
   - داخل صفحة المادة: يضغط المستخدم على أحد الأزرار السريعة الثلاثة (**أخطائي**، **محفوظاتي**، **ملاحظاتي**).
   - أو من الصفحة الرئيسية لبنك الأتمتة: يضغط على تبويب **الأخطاء** أو **المحفوظات** (مع التبديل بين محفوظاتي وملاحظاتي).
2. **المستوى الثاني (التبويبات الرئيسية الأربعة الثابتة)**:
   - يظهر شريط مقسم من 4 تبويبات رئيسية تبقى ظاهرة دائماً حتى لو لم توجد عناصر:
     - **الأقسام** (مع عداد العناصر)
     - **المحاضرات** (مع عداد العناصر)
     - **شامل وجزئي** (مع عداد العناصر)
     - **كامل** (مع إجمالي العناصر)
3. **المستوى الثالث (عرض الفروع أو الأسئلة)**:
   - في حال اختيار (**الأقسام** أو **المحاضرات** أو **شامل وجزئي**):
     - إذا لم يتم اختيار فرع بعد: تُعرض قائمة مرتبة بالفروع/المحاضرات التي تحتوي على عنصر واحد على الأقل (`count >= 1`)، مع إخفاء الفروع الفارغة تماماً لمنع الزحمة.
     - عند الضغط على الفرع (مثل «المحاضرة الأولى»): يظهر شريط علوي فرعي بعنوان المحاضرة وزر رجوع سريع (**«← العودة للفروع»**)، وتحته بطاقات الأسئلة التفاعلية الخاصة بهذا الفرع.
   - في حال اختيار (**كامل**):
     - تُعرض جميع الأسئلة المطابقة مباشرة في نفس الصفحة دون الحاجة لاختيار فرع.

### ب. مسار فتح ملف PDF في المكتبة العلمية
1. **الضغط الأول على ملف غير محمّل**: يبدأ التحميل التقدمي الدائري (`0%` ← `100%`) مع إمكانية الإلغاء، ويُحفظ الملف كـ `application/pdf`.
2. **الضغط على الملف بعد التنزيل**: يتم فتح الملف مباشرة كملف PDF خارجي عبر متصفح/عارض PDF في الجهاز دون إظهار قائمة تطبيقات المشاركة.

## 3. القرارات الهندسية والمفاضلات

- **القرار 1: إبقاء التبويبات الأربعة الرئيسية دائماً مع فلترة الفروع الداخلية فقط**
  - *النهج المختار*: التبويبات الأربعة (**الأقسام، المحاضرات، شامل وجزئي، كامل**) تبقى مرئية في كل الأوقات، بينما الفروع الداخلية تحت كل تبويب لا يظهر منها إلا ما يحتوي على أسئلة فعلية (`count > 0`).
  - *السبب*: يمنح الطالب ثباتاً بصرياً في التنقل ويعرفه فوراً بأي فئة توجد أخطاؤه أو محفوظاته أو ملاحظاته دون التشتت بفروع فارغة.
- **القرار 2: فتح PDF خارجي مباشر بدلاً من Web Share API**
  - *النهج المختار*: استخدام رابط `Blob URL` من نوع `application/pdf` مع فتح مباشر للـ PDF بدلاً من `navigator.share({ files })`.
  - *السبب*: استدعاء `navigator.share` على الهواتف يفتح قائمة المشاركة (واتساب، تلغرام، إلخ) بدلاً من عارض ملفات الـ PDF، بينما الرابط المباشر بصيغة `application/pdf` يوجه النظام لفتح الملف كـ PDF خارجي مباشرة.

## 4. البنية التقنية وإدارة الحالة

### مخطط تدفق البيانات والمكونات

```
┌──────────────────────────────────────────────────────────────────────────┐
│                        بنك الأتمتة (Automation Bank)                     │
├───────────────────────────────────┬──────────────────────────────────────┤
│     صفحة المادة (Subject View)    │      التبويب العام (Global Hub)      │
│  [أخطائي] [محفوظاتي] [ملاحظاتي]   │     [الأخطاء]    [المحفوظات/ملاحظات] │
└─────────────────┬─────────────────┴──────────────────┬───────────────────┘
                  │                                    │
                  ▼                                    ▼
┌──────────────────────────────────────────────────────────────────────────┐
│          شريط التصنيف الرباعي الثابت (دائماً مرئي حتى لو العدد 0)         │
│       [ الأقسام ]      [ المحاضرات ]      [ شامل وجزئي ]      [ كامل ]    │
└───────────┬──────────────────┬──────────────────┬────────────────┬───────┘
            │                  │                  │                │
            ▼                  ▼                  ▼                ▼
┌────────────────────────────────────────────────────────┐  ┌──────────────┐
│ الفروع غير الفارغة فقط (Branches with items > 0)       │  │ عرض مباشر    │
│ • المحاضرة الأولى (3 أسئلة) ──► فتح أسئلة المحاضرة     │  │ لكافة الأسئلة│
│ • المحاضرة الثالثة (1 سؤال) ──► فتح أسئلة المحاضرة     │  │ في صفحة واحدة│
└────────────────────────────────────────────────────────┘  └──────────────┘
```

### تفاعل المكونات وإدارة الحالة
- **حالة التصنيف الفرعي (`quickCategoryTab`)**:
  - القيم: `'section' | 'lecture' | 'comprehensive_partial' | 'all'`.
  - عند التبديل بين `أخطائي` و`محفوظاتي` و`ملاحظاتي`، أو التبديل بين التبويبات الأربعة، يتم تصفير الفرع المختار (`selectedQuickBranchId = null`) لعرض الفروع المطابقة فوراً.
- **حالة الفرع المختار (`selectedQuickBranchId`)**:
  - عند الضغط على فرع (مثل «المحاضرة الأولى»)، تنتقل الواجهة لعرض أسئلة ذلك الفرع فقط مع زر رجوع يعيد `selectedQuickBranchId` إلى `null`.
- **محرك فتح ملفات PDF الخارجي**:
  - التأكد من أن جميع الملفات المخزنة أو المولدة أوفلاين تحمل ترويسة `%PDF-1.4` صالحة ونوع MIME صريح `application/pdf`.
  - فتح الملف مباشرة عبر `Blob URL` بصيغة PDF دون استدعاء `navigator.share`.
